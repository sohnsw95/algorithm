## 러시아 국기 같은 깃발 · 완전 탐색

[원본 풀이](../SWEA/D4/4613.%E2%80%85%EB%9F%AC%EC%8B%9C%EC%95%84%E2%80%85%EA%B5%AD%EA%B8%B0%E2%80%85%EA%B0%99%EC%9D%80%E2%80%85%EA%B9%83%EB%B0%9C/%EB%9F%AC%EC%8B%9C%EC%95%84%E2%80%85%EA%B5%AD%EA%B8%B0%E2%80%85%EA%B0%99%EC%9D%80%E2%80%85%EA%B9%83%EB%B0%9C.py)

흰색·파란색·빨간색 구간의 경계 두 개를 고릅니다. 각 구간에서 이미 맞는 색의 칸을 세고, 그 합의 최댓값을 전체 칸 수에서 뺍니다.

- 시간: **O(N³M)**. 경계 조합 O(N²)마다 N개 행의 길이 M 문자열을 다시 셉니다.
- 공간: 입력 저장 **O(NM)**, 추가 계산 공간 O(1).
- 주의: 세 색의 구간은 각각 한 행 이상이어야 합니다. 코드의 경계 범위가 이 조건을 보장합니다.
- 개선 아이디어: 색별 누적합을 만들면 전처리 O(NM), 경계 탐색 O(N²)로 바꿀 수 있습니다. 이는 제안이며 기존 구현에 적용하지 않았습니다.

## 빙고 · 상태 갱신과 완성 조건

[원본 풀이](../%EB%B0%B1%EC%A4%80/Silver/2578.%E2%80%85%EB%B9%99%EA%B3%A0/%EB%B9%99%EA%B3%A0.py)

불린 숫자를 찾아 0으로 바꾸고, 매번 행·열·두 대각선의 완성 개수를 다시 셉니다. 3줄 **이상**이면 호출 횟수를 출력합니다.

- 실제 문제는 5×5 고정 크기입니다. 일반화한 N×N 판에 최대 N²개 호출을 적용하면 시간 **O(N⁴)**입니다.
- 공간: 판과 호출 목록 **O(N²)**, 열·대각선 계산의 임시 공간 O(N).
- 주의: 한 숫자로 여러 줄이 완성될 수 있으므로 `== 3`이 아니라 `>= 3`입니다. 0은 입력 숫자와 겹치지 않는 방문 표시입니다.

## 퍼펙트 셔플 · 홀수 길이 처리

[원본 풀이](../SWEA/D3/3499.%E2%80%85%ED%8D%BC%ED%8E%99%ED%8A%B8%E2%80%85%EC%85%94%ED%94%8C/%ED%8D%BC%ED%8E%99%ED%8A%B8%E2%80%85%EC%85%94%ED%94%8C.py)

두 묶음에서 카드를 번갈아 꺼냅니다. 길이가 홀수이면 앞 묶음이 한 장 더 많으므로 뒤 묶음 시작 위치를 한 칸 늦추고, 마지막에 앞 묶음의 남은 카드를 추가합니다.

- 시간 **O(N)**, 결과 리스트를 포함한 공간 **O(N)**.
- 주의: 홀수일 때 두 번째 묶음은 `N//2 + 1`에서 시작합니다. 문자열 출력 비용은 전체 카드 이름 길이에 비례합니다.

## 평균 일일 대여 요금 · 필터 후 집계

SUV 행을 WHERE로 선택하고 DAILY_FEE의 평균을 구한 뒤 정수 자리로 반올림합니다.

- 인덱스 없는 전체 순회 기준으로 행 수 R에 대해 시간 **O(R)**, 평균 집계 자체의 상태 공간 O(1).
- 실제 실행 비용은 데이터베이스 실행 계획·인덱스·데이터 분포에 따라 달라집니다. 실행 계획을 측정한 해설은 아닙니다.
- 주의: AVG는 NULL을 제외합니다. 개별 요금을 먼저 반올림하는 것과 평균을 낸 뒤 반올림하는 것은 다릅니다.
